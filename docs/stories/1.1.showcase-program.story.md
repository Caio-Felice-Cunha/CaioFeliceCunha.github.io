## Story

**As a** recruiter or technical peer, **I want** a curated portfolio with direct, safe demo paths, **so that** I can understand and test Caio's strongest work in under 60 seconds per project.

## Acceptance Criteria

1. The portfolio groups nine selected demos into AI Products, Live Products, Browser Automation, and Data Engineering.
2. Every project offers a demo or runnable path within two clicks and uses one of four honest status labels.
3. Unsupported claims, stale domains, and automatic emphasis on older repositories are removed.
4. The site contains no credentials, personal data, client material, or references to excluded projects.
5. Desktop/mobile smoke tests, keyboard navigation, link checks, and security scans pass.
